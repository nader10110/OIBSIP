---

## 📌 Objective
Perform exploratory data analysis on a retail sales dataset to uncover patterns, trends, and insights that help the business make informed decisions.

---

## 🛠️ Tools Used
| Tool | Purpose |
|------|---------|
| Python | Core programming language |
| Pandas | Data loading, cleaning, and manipulation |
| NumPy | Numerical computations |
| Matplotlib | Data visualization |
| Seaborn | Advanced data visualization |
| VS Code | Development environment |

---

## 📂 Dataset
- **Source:** Kaggle - Retail Sales Dataset

---

## 🔄 Steps Performed
1. Data Loading & Cleaning
2. Descriptive Statistics
3. Time Series Analysis
4. Customer Analysis
5. Product Analysis
6. Correlation Heatmap
7. Recommendations

---

## 📊 Key Insights
- 📈 Peak sales month identified with highest revenue
- 👩 Female customers represent the highest spending group
- 🧑 Age group 18-30 shows the highest average spending
- 💻 Electronics is the top-selling category
- 💰 Price per unit has a strong impact on total sales

Successfully performed end-to-end EDA on retail sales data, uncovering actionable insights across time, customer demographics, and product performance.
