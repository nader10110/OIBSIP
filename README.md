## 📁 Projects

### Task 1 - Retail Sales EDA
- **Folder:** 01-Retail-Sales-EDA
- **Description:** Exploratory Data Analysis on retail sales data
- **Tools:** Python, Pandas, Matplotlib, Seaborn

### Task 2 - NYC Airbnb Data Cleaning
- **Folder:** 02-NYC-Airbnb-Cleaning
- **Description:** Data cleaning and preprocessing on NYC Airbnb 2019 dataset
- **Tools:** Python, Pandas, Seaborn

### Task 3 - Customer Segmentation
- **Folder:** 03-Customer_Segmentation_Project
- **Description:** Customer segmentation using K-Means clustering
- **Tools:** Python, Pandas, Scikit-learn, Seaborn
