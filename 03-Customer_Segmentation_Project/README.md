# 👥 Customer Segmentation Analysis
### OIBSIP | Data Analytics | Task 3

---

## 📌 Objective
Perform customer segmentation analysis using K-Means clustering to group customers into distinct segments based on behavior and purchase patterns.

---

## 🛠️ Tools Used
| Tool | Purpose |
|------|---------|
| Python | Core programming language |
| Pandas | Data loading and manipulation |
| Matplotlib | Data visualization |
| Seaborn | Advanced visualization |
| Scikit-learn | StandardScaler & KMeans clustering |
| VS Code | Development environment |

---

## 📂 Dataset
- **Source:** Kaggle - Marketing Analytics Customer Segmentation
- **File:** ifood_df.csv

---

## 🔄 Steps Performed
1. Data Loading & Exploration
2. Data Cleaning
3. Feature Selection
4. Data Preprocessing (StandardScaler)
5. Optimal Cluster Selection (Elbow Method)
6. K-Means Clustering
7. Visualization & Insights

---

## 📊 Key Insights
- 👑 Cluster 0 - High Value: High income, high spending
- 🌱 Cluster 1 - Medium Value: Growth opportunity
- 💤 Cluster 2 - Low Value: Need re-engagement campaigns

---

## ✅ Outcome
Successfully segmented customers into 3 distinct groups providing actionable insights for targeted marketing strategies.
