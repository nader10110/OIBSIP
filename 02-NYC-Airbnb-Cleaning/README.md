# 🏙️ NYC Airbnb - Data Cleaning
### OIBSIP | Data Analytics | Task 2

---

## 📌 Objective
Clean and preprocess the New York City Airbnb 2019 dataset by handling missing values, removing duplicates, detecting outliers, and optimizing memory usage.

---

## 🛠️ Tools Used
| Tool | Purpose |
|------|---------|
| Python | Core programming language |
| Pandas | Data cleaning and manipulation |
| Matplotlib | Outlier visualization |
| Seaborn | Boxplot visualization |
| VS Code | Development environment |

---

## 📂 Dataset
- **Source:** Kaggle - [New York City Airbnb Open Data](https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data)
- **File:** AB_NYC_2019.csv
- **Records:** 48,895 rows × 16 columns

---

## 🔄 Steps Performed
1. Data Loading & Initial Exploration
2. Missing Data Handling
3. Duplicate Removal
4. Outlier Detection & Removal (IQR Method)
5. Data Standardization
6. Memory Optimization
7. Export Cleaned Data

---

## 📊 Key Results
- ✅ Missing values handled across all columns
- ✅ Outliers removed from price and minimum_nights
- ✅ Memory usage reduced after dtype optimization
- ✅ Clean dataset exported and ready for analysis

## ✅ Outcome
Successfully cleaned the NYC Airbnb dataset, ensuring data integrity, consistency, and reliability.
